# PC Pulse
## Инструкция
1. Скачать файл [PC Pulse.exe](https://drive.google.com/file/d/19DOVppwTtSAGCRLdR-8rRPJoGGQ8IqqS/view?usp=sharing) на ПК, запустить и дать все запрашиваеые разрешения.
2. Скачать файл [PC Pulse.apk](https://drive.google.com/file/d/1EtX8v4JEEv8QPadfKbkPzOpSzuABwB8v/view?usp=sharing) на смартфон и установить приложение.
3. В приложении на смартфоне нажать "+" и в диалоговом окне ввести IP и одноразовый код доступа показанные в окне приложения на ПК.

# PC Pulse
## Инструкция
1. Скачать файл [PC Pulse.exe](https://github.com/EgorDushenkov/PCPulse_V2/releases/download/V4/PC.Pulse.exe) на ПК, запустить и дать все запрашиваеые разрешения.
2. Скачать файл [PC Pulse.apk](https://github.com/EgorDushenkov/PCPulse_V2/releases/download/V4/PC.Pulse.apk) на смартфон и установить приложение.
3. В приложении на смартфоне нажать "+" и в диалоговом окне ввести IP и одноразовый код доступа показанные в окне приложения на ПК.

# Примечания:
    1. Желательно запускать агента от имени администратора.
    2. Виджеты создаются через способы в системе андройд, как правило это удержание на рабочем столе -> виджеты -> виджеты приложений, там ищите PC Pulse и просто создаете единственный доступный, после чего вы попадаете в конструктор виджета)
    3. Обновления одноразового кода не прерывают связи устройств на предыдущих кодах, а лишь лишают возможности связывать новые устройства на старых кодах.
    4. Для максимальной скорости отклика приложения не используйте ВПН на обоих устройствах.
